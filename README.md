# Mission Essaim

Escape game de 30 minutes pour la SNT en classe de seconde, thème Internet : l'intérêt des réseaux pair-à-pair et leurs usages illicites.

La station spatiale Essaim-4 a perdu son Cerveau central. Guidés par la commandante Vega-7 et l'IA NOÉ, les élèves explorent la station, résolvent des énigmes pour ouvrir les sas, puis répondent aux questions de l'activité à l'aide de blocs de phrases.

## Utilisation

Ouvrir `index.html` dans un navigateur sur PC, en mode paysage. Aucun compte n'est nécessaire.

Pour afficher un bouton d'envoi vers un Google Form sur la page de fin, renseigner `FORM_URL` dans `index.html`.
